# Opportunity Report Contract

Read this reference before creating or updating a Vicara report. Preserve these headings so another session can resume directly.

```markdown
# Repo Opportunity Report

## Destination

<what this pass must make possible>

## Repo Snapshot

- Purpose:
- Primary languages/formats:
- Important commands:
- Major areas:
- Guidance read:
- Areas ignored or sampled lightly:

## Frontier

- [ ] <area/question> — <why it matters; next check>

## Opportunities

### 1. <title>

- Category:
- Impact: <low | medium | high> — <why>
- Effort: <small | medium | large> — <why>
- Risk: <low | medium | high> — <why>
- Confidence: <low | medium | high> — <why>
- Agent suitability: <good | mixed | poor> — <why>
- Evidence:
  - `<path>` — <observed fact, verification method, and result>
- Suggested first step:
- Validation:

## Needs More Investigation

- <question/area> — <what is known; what remains>

## Out of Scope

- <area> — <why>

## Session Notes

### <date/session>

- Explored:
- Subagents used:
- Key findings:
- Next recommended action:
```

Order `Opportunities` by the skill's ranking algorithm. Keep `Frontier` actionable, put unresolved assumptions under `Needs More Investigation`, and record deliberate exclusions under `Out of Scope`.
